webhook(lemonsqueezy): dual-mode org/user subscription routing

Enhanced webhook handler to support both org-level and user-level subscriptions via custom_data. Routes org_id → orgs.plan and user_id → subscriptions table. Both paths supported in single POST.

- custom_data.org_id updates orgs(plan) to premium/free
- custom_data.user_id upserts subscriptions(plan, active) for user
- Validates at least one ID present
- subscription_created|updated + active → premium
- subscription_cancelled|status → free
